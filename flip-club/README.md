# 方寸对决 · Flip Club

一个无需安装依赖的策略翻牌网页游戏，包含自由对战与持续成长的无尽闯关。

- 闯关：逐关连续提高的强度、记忆容量、保留概率；每场结束后使用真实道具收益更新本地策略权重。
- 商城：首胜解锁，胜利获得金币；三种消耗补给、三种永久升级，装配槽限制以及非对称的对局配置。
- 闯关自动存档：保存进度、金币、库存、学习记录及未完成战斗，刷新后可恢复。

- AI 强度：初级、标准、大师三档记忆能力，每个机器人可以独立选择，也可统一应用；AI 只依据已公开的牌面决策。
- 好友同屏：2–8 位玩家自由添加真人和机器人，支持全机器人观战。
- 4×4、6×6、8×8、10×10、12×12 棋盘，72 种原创 SVG 牌面；支持标准/放大显示，空间不足时棋盘区域可横向滑动。
- 两张相同即消除并得分，连续配成两组后换人，失配换人。
- 初始 3 能量，配对或失配均恢复 1 点，上限 6 点。
- 九种道具，包括侦察、蓄力、换位、干扰、护盾、虹吸、雷达、记忆锚与破盾；每次尝试限一个，具有独立冷却和反制关系。
- 暂停、重新开局、结果与平局结算、可选音效、手机布局和键盘操作。

多人模式为同屏轮流，当前版本没有远程联机房间。

## 本地打开

macOS 双击 `启动方寸对决.command`，或运行 `python3 serve.py`。浏览器会自动打开游戏。关闭服务在终端按 Ctrl+C。

游戏资源全部在 `dist/`，无外部字体、图片或接口依赖。存档位于当前浏览器，不同浏览器和设备各自独立。自由对战保存设置，闯关另外保存完整未结束战斗。

## 验证

Node.js 18+ 下运行 `node --test tests/*.test.mjs`。自动化检查覆盖计分、反制、冷却、库存、重复奖励、存档与 AI 暗牌信息隔离。`node tests/balance.mjs` 可重跑 2,800 局模拟。设计来源、实际数值与局限见 `BALANCE.md`。

## 文件

`dist/engine.js` 是规则与 AI 引擎；`dist/campaign.js` 管理经济、进度与策略学习；`dist/campaign-ui.js` 管理关卡/商城界面和存档；`dist/app.js` 管理棋盘交互与动画；`dist/icons.js` 包含原创 SVG。静态网站无需构建即可部署。
